# Logos des moyens de paiement

Fichiers officiels récupérés le 26 octobre 2026, sans redessin ni recoloration. Les marques restent la propriété de leurs titulaires. Leur affichage se limite à la présentation du choix de paiement ; il ne constitue pas une annonce de partenariat.

- `wave.png` : https://www.wave.com/img/nav-logo.png · logo de navigation du site officiel Wave.
- `djamo.svg` : SVG du mot-symbole blanc extrait sans modification des tracés de https://www.djamo.com/fr-ci ; affiché sur un fond bleu sombre. Les attributs de taille et l’espace de noms SVG ont été adaptés pour son utilisation comme fichier image autonome.
- `mtn-momo-blue.png` : https://momodeveloper.mtn.com/content/momo_mtnb.png · fichier fourni par les directives de marque https://momodeveloper.mtn.com/content/html_widgets/1tio4.html ; présentation sur fond blanc dans le contexte paiement.
- `moov-money.png` : image 18 de la première page du document officiel https://www.moov-africa.ci/wp-content/uploads/2025/09/POLITIQUE-DCP-Site-internet.pdf, extraite sans redessin avec `pdfimages`.
- `orange-money.png` : image de la première page du document officiel https://orangemoney.orange.cm/orange-money/resources/other/General%20Terms%20and%20Conditions%20Of%20Use%20_%20ORANGE%20MONEY%20%20CAMEROUN%202026.pdf ; image RGB et masque alpha d’origine réassemblés pour préserver la transparence et les couleurs. Affichée sur fond blanc.

Le téléphone est un aperçu interactif construit en HTML/CSS, pas une capture d’une application en production. Ses paiements sont simulés et n’effectuent aucun débit.
